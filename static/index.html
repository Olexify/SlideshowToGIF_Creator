Start the editor with start.bat

This page needs its small local server, so it can't be opened as a file.

  1. Close this tab.
  2. Double-click start.bat in the SlideshowToGIF_Creator folder.
  3. The editor opens at http://127.0.0.1:8765/. Keep the black window open while you work.
